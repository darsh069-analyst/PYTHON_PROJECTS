## Projects

### 1. DataFrame Cleaner

**Technologies:** Python, Pandas, OS Module

A Python-based data cleaning tool designed to automate basic data preprocessing tasks.

**Key Features:**
- Reads CSV and Excel datasets.
- Identifies and removes duplicate records.
- Detects missing values.
- Handles numerical missing values using mean imputation.
- Removes rows containing missing categorical values.
- Exports duplicate records separately.
- Generates a cleaned CSV dataset.
